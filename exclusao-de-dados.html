Exclusão de Dados

Orientações para remover dados do Tô no Verde.

Versão atual: o Tô no Verde não exige criação de conta para utilizar o núcleo do aplicativo.

Dados armazenados localmente

Os registros financeiros e preferências principais da versão atual ficam no dispositivo do usuário. Para remover esses dados, o usuário pode:

  • usar a opção de apagar dados dentro do app, quando disponível;
  • acessar Configurações do Android → Apps → Tô no Verde → Armazenamento → Limpar dados;
  • desinstalar o aplicativo, observando que backups externos eventualmente criados pelo próprio usuário podem permanecer fora do app.

Solicitação de suporte

Se você acreditar que alguma informação sua foi efetivamente enviada e está sob responsabilidade do operador do Tô no Verde, entre em contato pelo e-mail atendimento@rayaconnect.com.br com o assunto “Exclusão de dados — Tô no Verde”.

Contas futuras

Se uma versão futura permitir criação de conta, esta página será atualizada para oferecer um caminho específico de exclusão da conta e dos dados associados, inclusive por meio web quando exigido pelas regras aplicáveis.
